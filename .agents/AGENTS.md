## Task Conclusion Protocol
- **Update README:** Always update the project's `README.md` file to reflect any significant changes, new features, or modifications made during a task.
- **Git Push:** At the end of every successful task or set of changes, commit the changes with a descriptive message and execute a `git push` to the remote repository.
- **Release & Versioning:** Create a new release and update the version tag on GitHub for every set of changes.
